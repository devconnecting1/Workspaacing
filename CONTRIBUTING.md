## Contributing

Thanks for your interest in contributing to **Workspaacing**! Your help is essential for keeping it great.

Contributions to this project are released to the public under the project's open source license.

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.

## Submitting a Pull Request

0. Fork and clone the repository
0. Install dependencies: `npm install`
0. Create a new branch: `git checkout -b feature/my-update`
0. Make your change and make sure the checks pass: `npm run ci:local`
0. Push to your fork and submit a pull request
0. Wait for your pull request to be reviewed and merged

Here are a few things you can do that will increase the likelihood of your pull request being accepted:

- Follow the existing code style (Biome handles formatting)
- Write clear commit messages with conventional prefixes (`feat:`, `fix:`, `chore:`)
- Keep your change as focused as possible
- Include screenshots for UI changes
- Reference any related issue in your PR

## Where to Contribute

- **Dashboard Screens**: `apps/web/src/app/(main)/dashboard/`
- **Auth Screens**: `apps/web/src/app/(auth)/`
- **Shared UI Components**: `packages/ui/src/`
- **Theme Presets**: `packages/theme/src/presets/`
- **Hooks & Utilities**: `apps/web/src/hooks/` and `apps/web/src/lib/`
